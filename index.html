DEARLOG GUIDE

기능 설명

자주 쓰는 기능들을 간단하게 정리했어요.

템플릿

X, Instagram, DM, 카카오톡 중 원하는 화면을 선택해 편집할 수 있어요.

오른쪽 편집 탭

오른쪽 패널은 `본문 수정하기`와 `화면 꾸미기`로 나뉘어요. 게시물/메시지 수정은 본문 탭에서, 배경·폰트·색상·출처는 화면 꾸미기 탭에서 설정할 수 있어요.

사진 편집

사진을 넣는 모든 곳에서 먼저 편집 창이 열려요. 파란 가이드가 실제 사진 틀과 같은 비율로 표시되며, 사진은 그 안에서 확대·축소와 위치 이동만 할 수 있어요. 적용하면 가이드에 보이던 구도 그대로 들어갑니다.

Instagram 사진 편집

Instagram 사진의 남는 여백 색상은 별도 설정 없이 일반 `배경` 색상을 사용해요. 사진 편집과 동영상 표시는 사진 편집 팝업에서 설정할 수 있습니다.

폰트

`화면 꾸미기 → 폰트`에서 기본 고딕·명조·둥근 고딕·고정폭을 선택할 수 있어요. 가진 TTF/OTF/WOFF/WOFF2 파일을 추가하면 사용자 폰트로도 Dearlog 전체 템플릿 글꼴을 바꿀 수 있어요.

프로필 사진

프로필 이미지를 선택하면 편집 팝업에서 확대·축소와 위치 조정을 한 뒤 적용할 수 있어요.

슬롯

슬롯에는 텍스트와 설정값만 저장돼요. 프로필·게시물·피드·메시지·배경 사진 등 업로드한 이미지 파일은 전혀 저장하지 않습니다. 슬롯을 불러온 뒤 사진만 다시 넣어 주세요.

자동 저장

작업 내용은 브라우저에 자동 저장되고, 새로고침하거나 다시 접속하면 마지막 작업을 자동으로 복원해요.

미리보기

편집용 버튼을 숨긴 실제 저장 화면을 확인할 수 있고, 미리보기에서도 바로 저장할 수 있어요.

저장

PNG는 바깥 영역을 투명하게 저장하고, JPG/PDF는 현재 템플릿 배경색으로 채워 저장해요.

저장 출처

오른쪽 패널의 `출처 표기`에서 그림 자료 출처 문구를 직접 수정할 수 있어요. 저장 꼬리표 왼쪽에는 `ⓒ + 그림 자료 출처`, 오른쪽에는 고정 사이트 출처 `Made with Dearlog`이 표시됩니다.
