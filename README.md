# Dearlog v100

## 이번 업데이트
- X / 인용 트윗 저장 실패 문제를 위해 저장 렌더링 방식을 재작성
- 기존 4배 고정 캡처를 제거하고 안정적인 2배 저장을 기본값으로 변경
- 저장 렌더링 실패 시 1.5배 → 1배로 자동 재시도
- 긴 X 템플릿은 처음부터 안전한 저장 배율을 자동 선택
- html2canvas의 foreignObjectRendering 비활성화
- 저장 전 편집용 선택 표시 / 사진 편집 배지 제거
- 다운로드 링크를 실제 DOM에 붙였다가 클릭 후 제거하는 방식으로 변경
- 저장 실패 시 단순 `저장에 실패했어요`가 아니라 실제 오류 메시지도 표시
- PNG / JPG / PDF 모두 동일한 재시도 로직 사용
