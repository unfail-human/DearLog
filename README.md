# Dearlog v44

## 이번 업데이트
- 사진을 넣는 모든 기능을 `사진 편집` 팝업 방식으로 통일
- X 첨부 사진, Instagram 피드, DM/카카오 사진 메시지 모두 업로드 전에 사진 편집 창 표시
- 기본 프로필, 상대/내 프로필, X 게시물별 프로필 사진도 동일한 사진 편집 창 사용
- 템플릿 배경 이미지와 채팅 배경 이미지도 사진 편집 후 적용
- 편집 창에서 사진 위치 조정, 확대/축소, 미리보기 후 적용 가능
- 사진 자체의 가로세로 비율은 늘리거나 찌그러뜨리지 않고 항상 유지
- X/Instagram 작업화면 위의 직접 드래그·휠 편집 기능 제거
- 기존 `휠 확대·축소 · 드래그` 안내를 `사진 편집` 표시로 변경
- 설명 팝업의 사진 관련 안내도 새 편집 방식에 맞게 수정
