# Dearlog v48

## 이번 업데이트
- 슬롯 저장 시 이미지 데이터를 저장하지 않도록 변경
- 자동 저장에서도 이미지 데이터를 제외
- 프로필 사진, 게시물 사진, Instagram 피드 사진, DM/카카오 사진, 배경 이미지는 슬롯/자동저장에 포함되지 않음
- 글, 이름, 아이디, 메시지, 색상, 배치, 사진 편집 설정값 등은 기존처럼 저장
- 슬롯 불러오기 시 이미지가 없는 위치에는 기본 프로필 이미지 또는 빈 사진 영역 표시
- 이미지 때문에 브라우저 localStorage 용량을 초과해 슬롯 저장이 실패하던 문제 완화
- 설명 팝업과 슬롯 안내 문구에도 이미지 미저장 정책 반영
