# Dearlog v15

- 기본 사람 실루엣 SVG를 다시 그려 머리/몸통이 원 안에서 잘리지 않도록 수정
- X / Instagram / DM / 카카오톡 전체 avatar 렌더링을 중앙 cover 방식으로 통일
- X 게시물 이름과 아이디의 세로 간격/위치 수정
- X 게시물 `•••` 메뉴에 `작성자 이름 · 아이디 수정` 추가
- 오른쪽 `QUICK EDIT / 본문 수정` 패널 추가
- X 게시물 클릭: 작성자 이름, 아이디, 본문 수정
- DM/카카오 메시지 클릭: 본문, 보내는 사람(상대/나), 시간 수정
- 입력중 표시 클릭: 오른쪽에서 `상대방 / 나`를 명확하게 선택 가능
- 메시지 `같은 쪽에 하나 더 보내기` 기능 추가: 연속 메시지를 빠르게 복제/수정 가능
- 선택 항목 삭제 기능을 오른쪽 패널로 이동
