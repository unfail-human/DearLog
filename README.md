# Dearlog v6

## 핵심 수정
- X / DM / 카카오톡 사진: 원본 비율 유지 + 화면 폭 자동 맞춤
- Instagram 피드: 3열 정사각형 그리드 유지, 9칸 이상도 잘리지 않도록 수정
- 미리보기 버튼 추가
- 미리보기와 PNG 저장 결과에서는 편집용 `동영상 표시`, `사진 추가` UI가 숨겨짐
- 플레이 아이콘(▶) 자체는 결과물에 유지
- 비어 있는 사진 슬롯은 미리보기/저장 시 숨김
- DM / 카카오톡 말풍선 최대 폭을 84%로 확대
- 양옆 패딩과 프로필 크기를 조정해 긴 메시지 가독성 개선
- Instagram의 게시물 수 / 팔로워 / 팔로잉 / 한줄소개는 기존처럼 직접 클릭 수정 가능
