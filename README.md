# Dearlog v72

## 이번 업데이트
- DM 메시지 입력창 복구 및 DM/카카오톡 세로 비율 재정리
- 스티커 기능을 본문 수정에서 분리하고 `스티커 스튜디오` 전용 탭 추가
- 스티커 스튜디오 활성화 시에만 작업화면에서 이동/크기 편집 가능
- 개별 스티커 잠금/잠금 해제 기능 추가
- 추가한 스티커를 이미지 썸네일 목록으로 표시하고 목록에서 선택 가능
- 잠긴 스티커는 실수로 이동/삭제되지 않도록 보호
- 출처 표기 체크박스를 제거하고 `표기 중 / 표기 안 함` 버튼으로 변경
- 출처 설정의 문구/컨트롤 간격 확대
- 슬롯/설명 버튼을 오른쪽 작업 여백으로 이동
