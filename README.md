# Dearlog v99

## 이번 업데이트
- X 인용 트윗 수정 후 미리보기는 되지만 파일 저장이 실패할 수 있던 문제 수정
- 저장 전에 인용 원본 프로필 사진을 포함한 모든 이미지의 로딩 완료를 확인
- 이미지 하나가 로드에 실패해도 전체 저장이 중단되지 않도록 안전 처리
- 저장 시 편집 화면의 확대/축소 배율을 제거하고 원본 100% 레이아웃으로 캡처
- X 게시물이 많아 템플릿이 길어진 경우 브라우저 Canvas 최대 크기를 넘지 않도록 저장 해상도를 자동 조정
- 일반 크기에서는 기존 최대 4배 고화질 저장 유지
- PDF 크기 계산도 실제 저장 배율에 맞게 수정
