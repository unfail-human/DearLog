# Dearlog v3

창작 캐릭터 / 관계성 / 이야기용 SNS 이미지 메이커.

## v3 추가 기능
- 카카오톡형 템플릿 추가
- Instagram 피드 기본 9칸
- 메인 색상 기반 자동 추천 팔레트
- 자동 추천 ON/OFF 및 배경/카드/포인트 수동 조절 유지
- DM / 카카오톡 상대 프로필과 내 프로필 각각 설정
- 양쪽 프로필 이미지 각각 업로드
- 텍스트 메시지 추가
- 사진 메시지 추가
- DM / 카카오톡 모두 사진 메시지 지원
- 기존 X / Instagram / PNG 저장 / 다크 모드 유지
