# Dearlog v95

## 이번 업데이트
- 저장 이미지에서 `Made with Dearlog`가 다시 왼쪽으로 이동하던 문제 수정
- 미리보기 / PNG / JPG / PDF용 출처 꼬리표는 Flex/Grid 정렬에 의존하지 않도록 변경
- 저장용 `Made with Dearlog`을 꼬리표 오른쪽 11px 위치에 절대좌표로 고정
- 커미션 출처는 왼쪽, 사이트 출처는 오른쪽으로 각각 독립 배치
- 커미션 출처를 생략해도 `Made with Dearlog`은 항상 오른쪽 유지
- 작업화면에서 보이는 출처 위치는 기존 그대로 유지
