# Dearlog v96

## 이번 업데이트
- X / Instagram / DM / 카카오톡 전체 바깥 프레임의 둥근 모서리 제거
- 작업화면을 완전한 직사각형 레이아웃으로 통일
- 미리보기에서도 모서리 빈 공간 없이 꽉 찬 직사각형으로 표시
- PNG / JPG / PDF 저장 결과에도 동일한 직사각형 프레임 적용
- 메시지 말풍선 / 입력창 등 템플릿 내부의 둥근 UI는 기존 디자인 유지
- 출처 꼬리표의 둥근 하단 모서리 제거
- `ⓒ 커미션 출처` 글자를 `Made with Dearlog`과 비슷한 진하기로 조정
- 출처 텍스트 opacity와 font-weight를 높여 저장 이미지에서도 또렷하게 표시
