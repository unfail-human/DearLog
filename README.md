# Dearlog v51

## 이번 업데이트
- 이미지 미저장 슬롯을 불러왔을 때 프로필에 액박이 표시되던 문제 수정
- 슬롯/자동저장에 프로필 사진이 없으면 Dearlog 기본 사람 실루엣으로 자동 대체
- X 게시글 화면에서 본문 / 작성자 이름 / 아이디를 직접 수정하는 기능 제거
- X 게시글 편집은 오른쪽 `게시글 수정` 패널에서만 가능하도록 정리
- 오른쪽 본문 입력 중 매 글자마다 전체 화면을 다시 렌더링하던 문제 제거
- 본문 textarea에서 키보드 입력이 취소되거나 되돌아가던 오류 수정
- 오른쪽에서 입력한 본문 / 이름 / 아이디를 현재 게시글 화면에 즉시 반영
