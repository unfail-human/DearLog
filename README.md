# Dearlog v22

- 업로드한 My Editor 아이콘 파일을 그대로 `favicon.png`로 적용
- 왼쪽 기본 프로필 이미지 미리보기를 72×72로 확대
- 오른쪽 `게시글 수정` 패널에 게시물별 프로필 사진 변경 기능 추가
- 오른쪽에서 게시물 프로필 사진 미리보기 / 이미지 선택 / 내 프로필 사진 사용 가능
- X 첨부 사진 영역은 240px 고정 유지
- X 사진 자체는 0.5배~4배 휠 확대·축소
- X 사진을 마우스로 드래그해서 위치 자유 조절
- 사진을 축소하면 지정한 사진 배경색이 뒤에서 보임

- v23: 투명 배경의 단일 반짝이 아이콘을 사이트 favicon으로 적용

- v24: 미리보기 창의 `저장`과 `닫기` 버튼을 한 줄 가로 배치로 정리

- v25: X 반응 버튼 활성 색상 추가
  - 답글: 파란색
  - 리트윗: 초록색
  - 마음: 빨간/핑크색
  - 활성화 시 아이콘과 숫자를 함께 진하게 표시

- v26: X 첨부 이미지 저장 위치 불일치 수정
- 저장/미리보기 직전에 현재 확대 배율, 드래그 위치, 배경색을 고해상도 이미지로 고정 합성
- 편집 화면에서 맞춘 사진 구도가 PNG/JPG/PDF에 그대로 반영

- v27: 가운데 작업 영역을 고정
- X 템플릿 제목/LIVE EDIT 영역을 왼쪽으로 이동
- 작업 화면을 가운데 칸의 왼쪽 상단 기준으로 배치
- 현재 템플릿 전체가 남은 작업 공간 안에 한 번에 보이도록 자동 축소
- 좌우 설정창을 스크롤해도 가운데 작업 화면은 움직이지 않음
- 자동 축소는 편집 화면에만 적용되며 저장 이미지 원본 크기에는 영향 없음

- v28: 메인 작업 화면을 가운데 정중앙으로 복구 및 고정
- 상단 템플릿 제목/설명은 왼쪽 유지
- LIVE EDIT 배지는 상단 오른쪽 끝으로 이동
- 자동 축소 시에도 작업 화면 중심 위치 유지
