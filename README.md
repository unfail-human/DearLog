# Dearlog v5

## 수정 사항
- 모든 템플릿 폭을 390px 휴대폰 규격으로 통일
- 템플릿 높이는 844px부터 시작하고 콘텐츠가 길어지면 아래로 자연스럽게 늘어남
- DM / 카카오톡 긴 대화 지원
- X형 사진 추가 안내를 이미지 박스 정중앙으로 수정
- X / Instagram / DM / 카카오톡 사진에 동영상 플레이 표시(▶) 토글 추가
- 기존 읽음/1 표시, 배경, 공지, 자동 팔레트, PNG 저장 유지

GitHub에는 `index.html`, `style.css`, `script.js`, `notice.js`를 업로드하세요.
