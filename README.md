# Dearlog v40

## 이번 업데이트
- 선택된 게시물 표시가 카드 가장자리에서 잘려 보이던 문제 수정
- 선택 표시를 바깥 outline 대신 카드 내부 테두리 방식으로 변경
- 프로필 사진 업로드 시 바로 적용하지 않고 편집 팝업을 열도록 변경
- 프로필 사진 편집 팝업에서 드래그 위치 조정 가능
- 100%~400% 확대/축소 가능
- 원형 적용 미리보기 제공
- 적용 시 1024×1024 고해상도 PNG로 다시 생성해 작은 프로필에서도 화질 저하 완화
- X / Instagram 기본 프로필, DM 상대/내 프로필, X 게시물별 프로필 사진에 동일 편집기 적용
