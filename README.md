# Dearlog v91

## 이번 업데이트
- 기존 텍스트 목록형 `기능 설명`을 실제 화면을 짚어 주는 단계별 가이드로 전면 변경
- 도움말 실행 시 나머지 화면에 회색 반투명 오버레이 적용
- 현재 설명 중인 실제 기능 영역만 밝게 유지하고 테두리/가이드라인으로 강조
- 설명 팝업을 강조된 기능 옆에 자동 배치
- 템플릿 선택 → 작업화면 → 본문 수정 → 화면 꾸미기 → 스티커 스튜디오 → 확대/축소 → 미리보기 → 저장 → 슬롯 순서로 안내
- 이전 / 다음 / 완료 버튼과 키보드 방향키 이동 지원
- 도움말을 닫으면 강조 효과와 오버레이가 모두 제거
